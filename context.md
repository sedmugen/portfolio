# Portfolio Master Context

See full documentation and specifications in [docs/context.md](file:///d:/GitHub/portfolio/docs/context.md).

## Quick Reference
- **Stack**: Next.js 15 (App Router), TypeScript, Tailwind CSS, Framer Motion, Vercel
- **Content Model**: Local TypeScript files in `/content/projects/*.ts`
- **Sitemap**: `/` (Home), `/work` (All Projects), `/work/[slug]` (Project Detail), `/about` (About), `/contact` (Contact)
- **Design Language**: Editorial, minimal, warm off-white (`#F7F6F3`), near-black (`#141414`), whitespace-driven exhibition of work.
