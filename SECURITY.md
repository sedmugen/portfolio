# Security Policy

The **Saad Mughal Portfolio** project takes security and vulnerability reporting seriously.

---

## 1. Supported Versions

Security fixes and dependency updates are applied directly to the active `main` branch.

| Version | Supported          |
| :--- | :--- |
| `main` (Latest) | :white_check_mark: |
| `< 0.1.0` | :x: |

---

## 2. Reporting a Vulnerability

If you discover a security vulnerability or sensitive data exposure within this repository, please report it privately rather than opening a public issue.

### Reporting Process
1. Send an email to **[saadmughal321@gmail.com](mailto:saadmughal321@gmail.com)** with the subject line:
   ```
   [SECURITY] Potential Vulnerability in sedmugen/portfolio
   ```
2. Include the following details in your report:
   - Description of the vulnerability or risk.
   - Steps to reproduce or proof of concept.
   - Affected components, routes, or dependencies.
   - Potential impact.

### Response Timeline
- **Initial Response**: Within 48 hours acknowledging receipt.
- **Assessment & Triage**: Within 5 business days.
- **Resolution**: A patch or dependency update will be deployed promptly upon verification.

Thank you for helping keep this project secure.
