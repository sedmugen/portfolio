# Vision

## One sentence

Create a sophisticated, editorial, visual-first portfolio that feels like a curated exhibition of things Saad has built, combining the restraint and project-presentation philosophy of high-end creative portfolios (reference: Eizo) with a distinct identity suited to software, games, AI, and design work.

## Purpose

This site exists for one job: **career** (job applications, internships, employer-facing outreach). Every decision, copy, tone, what gets featured, what gets cut, is filtered through "does this help someone hiring a builder decide to talk to Saad." It is not a client-acquisition site (that's onepercent.ink) and not a personal brand/lifestyle site.

## Core identity

The site is a **curated creative/developer portfolio**, not a resume website and not a SaaS landing page.

Central message: **I build things.**

The work spans software, games, AI/technical projects, and design/visual work. The site communicates craft and range through the work itself, not through paragraphs of self-description.

**Is:** editorial, minimal, sophisticated, visual, quietly confident, slightly experimental.

**Is not:** corporate, SaaS-template, generic "developer portfolio," resume-in-website-form.

## Reference philosophy

Eizo (eizo.framer.website) is a philosophical reference for:
- large, confident visual project presentation
- generous whitespace
- restrained typography
- minimal navigation (Home / Info / Projects / Contact, 4 items, no more)
- project-first design where the work dominates over UI chrome
- subtle interaction, not decorative animation

The site should not visually copy Eizo. Eizo is a videography portfolio; Saad's site needs to carry code, product screenshots, game stills, and design work, a different visual language, same discipline.

## The most important design principle

**The portfolio should exhibit the work rather than explain it.**

Text supports the visuals. It doesn't compete with them. A visitor should be able to scroll the homepage and understand "this person builds interesting, varied things" before reading a single paragraph of prose.

## Don't over-design it

The projects themselves are already visually diverse (a desktop app, a genetic-algorithm scheduler, a game, a luxury e-commerce concept, a roofing lead-gen site). The portfolio's job is to be a **quiet, consistent stage** for that diversity, not to compete with it stylistically. Restraint is what makes it read as expensive rather than a pile of effects.

## Non-goals

- Not a blog
- Not a full CV/resume replacement (no downloadable resume, every job needs a tailored CV, handled separately)
- No "skills bars" or percentage ratings
- No pricing/services page (that's One Percent's job, this site only *shows* the One Percent site as a project)
- SlushBox Studios is explicitly out of scope
